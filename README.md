## **Pathogen Pursuit**

An educational, local multiplayer game for learning about diseases.

Take turns guessing where a given disease was first identified. After each player makes a guess, the game reveals details about the disease, including when it was identified, how it spread, and possible prevention methods. Points are awarded for precision; the closer your guess is to the actual location, the more points you get. Have the most points at the end of the 5 rounds to win!

Panning the map - Hold and click the left mouse button to drag
Zooming in/out - Scroll the mouse wheel up/down
Placing/replacing a guess - Tap the left mouse button
